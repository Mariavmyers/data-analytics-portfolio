# Healthcare Language Services Operations Analytics

## Project Status
In progress

## Business Problem
A healthcare language-services operation needs to understand when and where interpreter demand may contribute to longer connection times, abandoned requests, and service-quality risk.

## Analytical Goal
Identify operational bottlenecks and determine which languages, time periods, modalities, or service conditions should be investigated first for potential capacity or workflow improvements.

## Questions to Answer

- When is interpreter demand highest?
- Which languages experience the longest connection times?
- What is the session abandonment rate?
- How do OPI and VRI performance compare?
- What percentage of sessions connect within the target service window?
- Are technical issues or long waits associated with lower satisfaction?

## Planned KPIs

- Total session volume
- Completion rate
- Abandonment rate
- Average connection time
- Service-level attainment
- Average session duration
- Customer satisfaction score (CSAT)
- Technical issue rate

## Tools

- Excel — data inspection, validation, pivot analysis
- SQL — querying, aggregation, KPI calculations
- Power BI — interactive operational dashboard
- Python / pandas — exploratory and deeper analysis

## Data
This project uses a synthetic dataset created for educational and portfolio purposes. It is designed to resemble realistic healthcare language-services operations without representing the actual performance of any employer or organization.

No proprietary employer data, protected health information (PHI), patient information, customer information, or confidential business information is used.
